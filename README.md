# Anjali Jha — React.js Frontend Developer Portfolio

A premium dark, animated React/Vite portfolio inspired by the visual language of the provided reference portfolio, but built as an original design.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Add your resume

Put your actual PDF at:

`public/Anjali-Jha-Resume.pdf`

The Hero "Download Resume" button will then work.

## Add GitHub / Live Demo URLs

Edit `src/data.js` and replace the `#` values for each project:

- `github`
- `live`

No URLs were invented.

## Deploy

### Netlify
Build command: `npm run build`
Publish directory: `dist`

### Vercel
Framework preset: Vite
Build command: `npm run build`
Output directory: `dist`
